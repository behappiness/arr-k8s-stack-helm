  Windows  net use Z: \<host>\{{ .Values.share.name }} /user:{{ .Values.auth.username }}

{{- if .Values.share.readOnly }}

The share is read-only. Set share.readOnly=false to allow writes - but a
client that can delete files the *arrs believe they own causes confusing
failures, so prefer a separate writable share for drop-offs.
{{- else }}

WARNING: share.readOnly is false. Files written over SMB are created as
UID {{ .Values.auth.uid }}, which the other applications also use, so imports
keep working - but a client can also delete media the *arrs are tracking.
